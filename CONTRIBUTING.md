# Contributing to Viralis

First off, thank you for considering contributing to Viralis! It's people like you that make Viralis such a great tool.

## Code of Conduct

By participating in this project, you are expected to uphold our Code of Conduct.

## How Can I Contribute?

### Reporting Bugs

- Use the **Bug Report** template when creating an issue.
- Provide a clear summary and steps to reproduce.

### Suggesting Features

- Use the **Feature Request** template.
- Explain why the feature would be useful to the project.

### Pull Requests

1.  **Fork the repo** and create your branch from `main`.
2.  **Ensure code quality**: Run `./scripts/install-hooks.sh` to setup local linting.
3.  **Tests pass**: Ensure all automated checks pass before pushing.
4.  **Describe your changes**: Use the PR template provided by GitHub.

## Development Standards

### Branching Model

- `main`: Production-ready code.
- `feature/*`: New features.
- `bugfix/*`: Bug fixes.

### Code Style

- **Python**: PEP 8 (enforced by `black`, `flake8`).
- **Go**: `gofmt`.
- **JavaScript/TypeScript**: Airbnb style guide.

### Commits

- Use descriptive commit messages.
- Reference issue numbers (e.g., `Fixes #123`).

## Questions?

Feel free to open a discussion or contact the maintainers.
